# INKFLOW · 먹의 흐름

다섯 빛깔 먹(오방색)의 기운을 다루는 탑다운 액션 로그라이트.
가장 강한 먹의 기운이 캐릭터의 3타 콤보를 통째로 바꾼다. 모든 그림은 코드로 그린 수묵화다.

한 판은 병풍 한 틀, 방 하나는 그림 한 폭이다. 방을 다 그려 내면(먹귀를 모두 쓰러뜨리면) 낙관이 찍히고,
담장에 그려지는 달문에서 다음 방의 먹과 종류를 보고 길을 고른다. 장은 대숲(竹)·연못(蓮)·산사(寺) 셋이고, 장의 마지막 방에는
주인(묵호 墨虎, 이무기 螭, 봉황 鳳)이 기다린다. 장 사이에는 정자에서 숨을 고른다. 산사의 방에는 범종이 있어, 붓으로 치면 종소리가 먹귀를 굳힌다.
먹방울로 얻은 젖은 먹은 싸우는 동안 마르고, 물건이 붙잡은 굳은 먹은 남는다. 주속성이 80을 넘으면 태과(太過) — 강해지지만 대가를 치른다.
장을 마치면 그린 방들이 화첩으로 남는다.
첫 화면에서 끝없는 물결(한 방에서 계속 버티기)도 고를 수 있다.

- 바로 하기: https://sx2xoox.github.io/INKFLOW/
- 기획서: [docs/GDD.md](docs/GDD.md)

## 실행

기본 브랜치에 올리면 GitHub Actions가 빌드해서 GitHub Pages로 내보낸다(`.github/workflows/deploy.yml`).
로컬에서 돌릴 때는:

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일
```

## 조작

| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 걷기 |
| 마우스 | 겨누기 |
| 왼쪽 클릭 (누르고 있기) | 3타 콤보 |
| Space / 오른쪽 클릭 | 비켜 서기(대시) |
| F | 자동 휘두르기 |
| Esc | 멈춤 |
| 1–5 | 보상 카드 고르기 |

## 개발용 주소

| 주소 | 내용 |
|---|---|
| `?debug` | 1–5 키로 먹 기운 +10 (Shift는 −10), N 키로 먹귀 모두 쓰러뜨리기 |
| `?demo` | 스스로 싸우는 시연 |
| `?gallery=jeok` | 한 먹의 세 획과 상태 효과를 멈춘 채로 보기 (`cheong` `jeok` `hwang` `baek` `heuk` `plain`) |
| `?gallery=enemies` | 모든 먹귀를 색별로 보기 |
| `?boss` | 곧장 장의 주인과 싸우기 (`?boss=jeok`처럼 먹을 고를 수 있다). `&ch=1`이면 연못의 이무기, `&ch=2`면 산사의 봉황 |
| `?shop` | 곧장 문방으로 (`&ch=1`이면 연못, `&ch=2`면 산사) |
| `?rest&ch=1` | 곧장 장 사이의 정자로 (`&ch=2`면 산사 어귀) |
| `?room=2&ch=1` | 곧장 그 장의 그 방(싸움)으로 |
| `?sheet=lotus` | 먹잉어·먹거북 자세와 이무기 머리를 크게 늘어놓아 보기 |
| `?sheet=temple` | 먹여우·돌사자 자세, 봉황의 몸, 석탑·단풍나무·종각·범종을 크게 늘어놓아 보기 |
| `?items=pine-soot,brazier` | 물건을 지니고 시작 (`?boss`, `?shop`과 함께) — 이름은 `src/game/artifacts.ts` |
| `?sheet=tiger` | 묵호의 자세들을 크게 늘어놓아 보기 |
| `?res=1` | 그리는 해상도를 고정 (기본은 기기에 맞춰 저절로 조절) |

`?demo`와 `?gallery`는 시작 화면 없이 바로 들어간다.

## 구조

```
src/
  ink.ts            오방색 먹, 상극·상생, 젖은 먹·굳은 먹, 마르기, 태과
  game/             게임 규칙 (렌더링과 무관)
    game.ts         방 진행, 물결, 피해, 콤보 진행
    rooms.ts        장과 방 종류, 배치(바위·대숲·버드나무·물), 먹귀 무리, 다음 문
    boss.ts         대숲의 주인 묵호의 동작, 주인들이 함께 쓰는 포효와 먹 갈아입기
    imugi.ts        연못의 주인 이무기 — 마디를 따라가는 몸, 잠기고 솟는 동작
    characters.ts   캐릭터와 먹별 3타 콤보 정의
    moves.ts        동작 판정 모양
    enemies.ts      먹귀 정의와 행동
    items.ts        보상 카드와 물건을 얻는 길
    artifacts.ts    물건 — 효과와 붙잡는 먹
  render/           캔버스 붓 도구 (그림을 굽는 데 쓴다)
    brush.ts        붓질, 먹 덩이, 먹 튐
    sprites.ts      붓잡이와 먹귀 그림
    paper.ts        한지
    room.ts         방 그림(담장·디딤돌·샘·물·연잎·갈대)과 바위·대숲·버드나무
    tiger.ts        묵호 그림(자세 값으로 움직이는 몸)
    imugi.ts        이무기 머리 그림
  gfx/              PixiJS 렌더링
    strokes.ts      GPU 붓질 셰이더
    composite.ts    한지 합성 셰이더
    paperfx.ts      한 번 구워 두는 종이결
    governor.ts     기기에 맞춰 그리는 해상도 조절
    inksim.ts       먹 번짐 시뮬레이션
    fx.ts           콤보 궤적과 효과
    view.ts         장면 구성
    hud.ts          화면 표시
  ui.ts             첫 화면, 보상, 끝 화면
```
